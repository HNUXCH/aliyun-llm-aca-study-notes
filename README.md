## 一、考试概览

**认证定位**：Alibaba Cloud Certified Associate - LLM，面向企业 AI 通识教育，适合非技术背景人员、无算法背景的技术人员，以及希望系统了解大模型应用方法的学习者。

**考核核心**：对大模型基础知识、典型应用方式、AI Agent 使用方法和安全合规要求的理解，以及将大模型能力应用到实际业务场景中的能力。

**重要说明**：本认证**不要求编写代码，不考模型训练和协议实现细节**。考试重点是理解大模型能力边界，并能在业务场景中选择合适的方法：优化输入、接入知识库、调用工具、使用微调、协作 Agent，或保留人工确认。

## 二、通过认证可证明的能力

1. 了解大模型的基本概念、工作原理和常见应用场景，能够与大模型相关技术人员进行基本沟通协作；
2. 掌握提示词工程、RAG、知识库、工具调用、MCP、微调、Agent 和 Skill 等改进大模型应用效果的方法；
3. 能够使用大模型和个人 AI Agent 辅助完成信息提取、内容生成、资料分析、知识问答、办公自动化等任务；
4. 理解如何围绕业务目标和评测机制打造面向他人的高质量 AI 服务；
5. 了解大模型应用，尤其是 Agent 应用中的安全合规风险来源与治理方法。

## 三、学习建议

- **前三章占 60% 分值**（增强能力 22% + 提示词 20% + 大模型概念 18%），优先吃透；
- 第 5 章 Agent（16%）次之；第 4 章微调、第 6 章安全合规各占 12%，以记忆要点和选型边界为主；
- 全卷贯穿一条主线——**「选型」**：什么问题用提示词优化、什么问题接 RAG、什么问题靠工具、什么情况才微调、什么环节必须人工确认。每章的对比表是高频考点；
- 每章末尾附有自测题（含答案解析），建议学完一章立即自测；
- 多选题占 30 分且要求对每个选项精确判断，是拉开分数差距的关键。
